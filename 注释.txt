Gym 可视化中的彩色点含义
根据 
humanoid_char.py
 中的代码：

🔴 红色点 color=(1, 0, 0)
humanoid_char.py#604
geom = gymutil.WireframeSphereGeometry(sphere_size, 32, 32, None, color=(1, 0, 0))
机器人当前实际的关键身体部位位置 (rigid_body_states)，即机器人在仿真中实时的关节/身体位置。

🟢 绿色点 color=(0, 1, 0)
humanoid_char.py#653-655
color = (0, 1, 0)
geom = gymutil.WireframeSphereGeometry(sphere_size, 32, 32, None, color=color)
ref_key_body_pos = self._ref_body_pos[:, self._key_body_ids, :3]
参考动作的全局关键身体部位位置 (_ref_body_pos)，即目标动作数据中的全局坐标位置。_

🔵 青色点 color=(0, 1, 1)
humanoid_char.py#613
color = (0, 1, 1)
参考动作的局部关键身体部位位置（相对于机器人当前 root 位置转换后的参考位置）。

🟡 黄色点 color=(1, 1, 0)
legged_robot.py#998
sphere_geom = gymutil.WireframeSphereGeometry(0.02, 4, 4, None, color=(1, 1, 0))
高度测量采样点 (
_draw_height_samples
)，用于地形感知的高度测量点位置。_

总结：

红色 = 机器人实际位置
绿色 = 参考动作目标位置（全局）
青色 = 参考动作目标位置（局部坐标系）
黄色 = 高度测量点（如果启用地形测量）
训练时，红色点和绿色/青色点越接近，说明动作跟踪效果越好。
